Berkeley

1. What is Berkeley Algorithm?
Answer:
Berkeley Algorithm is a clock synchronization algorithm used in distributed systems to synchronize the clocks of multiple machines connected in a network.
It uses:
one master machine (Time Daemon),
multiple slave machines.
The master calculates an average time and sends adjustment values (offsets) to all slaves.
Complete Working of Berkeley Algorithm
Step-by-Step Working

Step 1 — Master Polls All Slaves
The Time Daemon (master) requests current time from all slave machines.
Example:
Master Time = 10:00:00
Slave1 Time = 10:00:04
Slave2 Time = 09:59:58
Slave3 Time = 10:00:02

Step 2 — Collect Clock Values
Master receives all clock times.

Step 3 — Calculate Average Time
Formula:
Average Time

Step 4 — Calculate Offsets
Master computes:
Offset=Average Time−Local Time
Example:
Machine	Offset
Master	+1 sec
Slave1	-3 sec
Slave2	+3 sec
Slave3	-1 sec

Step 5 — Send Offsets
Master sends offset values to each slave.

Step 6 — Adjust Clocks
Each machine updates its clock using:
New Time=Current Time+Offset
All clocks become synchronized.
Final Result
All machines show approximately same time.

2. What is the role of Time Daemon in Berkeley Algorithm?
Answer:
Time Daemon acts as the master server.
Responsibilities:
polls slave clocks,
computes average time,
calculates offsets,
synchronizes all clocks.

3. Why is clock synchronization required in distributed systems?
Answer:
Different machines have different clock timings due to clock drift.
Synchronization is needed for:
transaction ordering,
logging,
distributed databases,
event coordination,
consistency.

4. What is clock drift?
Answer:
Clock drift is the gradual difference in time between clocks of different machines.

5. How does Berkeley Algorithm differ from Cristian’s Algorithm?
Berkeley Algorithm	Cristian’s Algorithm
Uses average time	Uses UTC server time
Internal synchronization	External synchronization
Master computes average	Client synchronizes with server

6. Is Berkeley Algorithm centralized or decentralized?
Answer:
It is a centralized algorithm because synchronization is controlled by one master machine.

7. Does Berkeley Algorithm use UTC time?
Answer:
No.
It uses internally calculated average time instead of UTC.

8. What happens if the master machine fails?
Answer:
Synchronization stops because the algorithm depends entirely on the master.
This is called:
single point of failure

9. What is offset in Berkeley Algorithm?
Answer:
Offset is the amount of adjustment required to synchronize a machine’s clock.
Formula:
Offset=Average Time−Current Time
